## 二、生成器的确定性纪律

生成器放在 `tools/`，用标准库实现，**不引入第三方依赖**：

| 纪律 | 做法 |
|---|---|
| 随机源 | 自研 splitmix64 类确定性 RNG，**禁用 `random`**；固定 seed |
| 时钟 | **不读系统时钟**；所有日期由 seed 与序列推导 |
| 排序 | 显式排序键，禁用 `set` 迭代序；`dict` 按插入序构造 |
| 写出 | `ZIP_STORED` + `create_system=0` + 固定 `date_time=(1980,1,1,0,0,0)`；CSV 用 `\n` 与 `utf-8` / `gb18030` 显式编码 |
| 校验 | `tools/gen_data.py --check`：重跑生成器到临时目录，与入仓产物逐字节比对 |

**两层守门**：① 冻结产物自身形态正确（结构、白名单、覆盖度）；
② 重跑生成器 → 与冻结产物逐字节一致。只做①会在生成器被改坏时照常绿。

## 三、合成数据设计

### 3.1 假代码与假账号

- 证券代码段 `699000–699099`；名称一律 `示例` 前缀
- 资金账号 `Y0000001–Y0000009`；股东账号 `A000000001–A000000009`
- 账户别名 `示例账户一–示例账户九`
- 检查脚本断言：样例中代码 ∈ 白名单、名称以 `示例` 开头、无 8 位以上纯数字串

### 3.2 样例必须刻意注入的形态

对照 `data/rules/manifest.json` 的 `coverage.surfaces`，M2 起共 31 个形态：

- **导入 9 类**：海通 xlsx、华西 Tab+GB18030、UTF-8 CSV、GB18030 CSV、
  `="..."` 单元格、缺列、错位列、空文件、仅表头
- **成本 6 类**：同日多笔、部分卖出、清仓后再买入、送转后卖出、
  双口径产生差异的构造用例、**费用未分列**（M2 新增）
- **公司行为 6 类**：分红、送转、配股、拆分、分红再投、**无法识别（必须进待确认）**
- **归因 6 类**：单笔一次性投入、多笔定投、中途大额赎回、负收益、
  零收益、期末市值为 0
- **合并 4 类**：两账户、三账户、账户间划转、同名标的重叠持仓

**"无法识别"必须被注入**：否则"未识别行进待确认队列"这条纪律在基准上不可见。

### 3.3 真值台账

- 与样例**同源生成**（同一 seed、同一生成逻辑）
- 逐条登记：双口径成本与已实现收益、公司行为事件前后值、XIRR 期望值、
  划转清单
- **只存输入 + 期望**；观测由基准运行时实算
- 期望值必须能由输入**独立复算**——"把引擎注释掉，真值还能算出来吗？"
- 另附**一份独立手工算例**（Excel 口径）作为第二判据

### 3.4 覆盖度双登记

`coverage.surfaces` 逐形态登记 `surface / total / sampled`，
测试断言 `total == sampled`。**显式声明"抽样覆盖、非穷举"**，
不给"全券商支持"的错觉。

## 四、数据流入与流出

```
用户交割单（本机 _private/ 或任意路径）
   │  ← 只读取，不复制、不上传、不缓存到仓库
   ▼
import → 统一流水 + 错误台账 + 指纹台账（--out-dir）
   ▼
cost / pnl / corporate-actions / attribution / merge
   ▼
report → 单文件 HTML（打码后） + report_data.json
```

**隐私边界**：

- 导入阶段只读用户指定文件，不写回原目录
- 报告阶段打码发生在**生成时**，HTML / JSON 不含完整账号
- 任何产物默认落 `--out-dir`，不进仓库（`.gitignore` 已锚定）
- 真实交割单放 `_private/`，已忽略

## 六、数据不漂移守门

| 守门 | 断言 |
|---|---|
| 生成器 `--check` | 重生成与冻结产物逐字节一致（两层：产物形态 + 重生成比对） |
| 白名单扫描 | 代码段 / 名称前缀 / 账号形态全部合规 |
| 覆盖度锁定 | `total == sampled`，形态集合与 manifest 完全一致 |
| 真值库形态 | 无 `observed_*` 字段；每项期望可由输入复算 |
| 隐私扫描 | 样例与真值台账中无 8 位以上纯数字串、无真实账号形态 |
| 入仓隔离 | `_private/` 与真实交割单不在 `git ls-files` 中 |

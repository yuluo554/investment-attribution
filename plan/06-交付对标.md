## 三、边界承诺对标（plan/01 §六）

| 边界 | 实现方式 | 可核验方式 |
|---|---|---|
| 不做投资建议 | 输出只含历史核算；无评分/排名/信号字段 | 报告字段清单 + 词面扫描 |
| 不登录券商、不下单 | 无任何券商接口代码；无凭据字段 | 静态扫描无网络栈（M0 已锁） |
| 不做消费流水 | 只处理证券/基金成交与持仓 | 输入 schema 无消费分类字段 |
| 不强制联网行情 | 行情与基准均为可选本地 CSV | 断网全流程 `exit 0`（M5） |
| 不承诺全券商支持 | 只承诺两类实测格式 + 通用映射 | README 覆盖度声明 + `unknown` 清单 |
| 不做基金 PDF / OCR | 扩展项，不进首期 DoD | plan/01 扩展项段 |
| 隐私红线 | 零上传、生成阶段打码、真实件不入仓 | 静态门禁 + 报告扫描 + `.gitignore` |
| 免责红线 | README + 报告免责段 | README 免责声明节 |
| 品牌隔离 | 不提及同方向其他项目业务领域 | 发布前人工复查 |
